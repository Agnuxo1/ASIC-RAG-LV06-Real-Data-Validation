# ASIC RAG LV06 Real Data Validation

<!-- impact-note:start -->
<sub><strong>Efficiency and practical value.</strong> The validation scripts and reports make ASIC-reservoir, entropy and retrieval claims testable through explicit controls and failure criteria. This helps focus follow-up experiments on defensible mechanisms and avoid spending compute on unsupported interpretations of mining behavior. Reusing existing hardware is a research objective; the immediate contribution is transparent experimental scrutiny documented in <a href="README_VALIDATION.md">the validation protocol</a>.</sub>
<!-- impact-note:end -->

## Repository scope

Experimental scripts, measurements and reports for Lucky Miner LV06 research. The materials examine mining telemetry, entropy, reservoir-computing hypotheses and retrieval claims.

Start with [the validation protocol](README_VALIDATION.md), which separates hypotheses, controls and pass/fail criteria. [The scientific-integrity report](SCIENTIFIC_INTEGRITY_REPORT.md) records another experimental interpretation. These documents should be compared with their associated methods and raw measurements; their conclusions are not interchangeable.
